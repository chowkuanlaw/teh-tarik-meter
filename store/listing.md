## English (en-US)

### Description

Your Claude usage as a living glass of teh tarik.

Teh Tarik Meter is a cute desktop widget that shows your Claude session and weekly limits as they change. The tea level is your current session: it drains as you chat and refills when your limit resets. Seven little cups show your week.

• A glass with feelings. It smiles when there's plenty left, gets worried near the limit, and falls asleep when you're out. A countdown shows your next refill.
• Know when you'll run out. "At this pace: runs out 4:02 PM", with optional alerts at 80% and 95% and before you run out.
• History. A chart of your day and your week.
• Instant with Claude Code. Connect Claude Code and the glass moves the moment a reply lands. Your own status line keeps working.
• Your drink, your look. Teh tarik, kopi O, Milo ais, teh ais or sirap bandung. Light or dark, English or Bahasa Melayu, normal or larger text, or a small compact strip.
• Stays out of your way. Hides during full screen apps and presentations. Ctrl+Alt+T shows or hides it.
• Festive outfits for Hari Raya, Chinese New Year, Deepavali, Kaamatan, Gawai, Merdeka, Malaysia Day and Christmas.
• And a little surprise, for the curious.

You need a Claude account (claude.ai). Sign in once on claude.ai's own page inside the app. The meter reads the same numbers as your Settings › Usage page. It never reads your chats, has no server of its own and sends nothing about you anywhere else. Not signed in yet? Tap "Peek at a sample first" to see it with made-up numbers.

Teh Tarik Meter is an independent app. It is not made, endorsed or supported by Anthropic. Claude is a trademark of Anthropic, PBC. Milo is a trademark of Société des Produits Nestlé S.A., used here only as the name of a drink; Teh Tarik Meter is not connected with Nestlé.

## Submission options

### Restricted capability: runFullTrust (why it's needed)

Teh Tarik Meter is a desktop widget built with Electron, packaged with the Desktop Bridge. It needs full trust to show a frameless always-on-top widget on the desktop, show a notification area (tray) icon, register a global keyboard shortcut (Ctrl+Alt+T), check whether a full screen app or presentation is running (SHQueryUserNotificationState) so it can hide itself, and start with Windows through its startup task. It does not install drivers or services, does not run elevated, and does not change system settings.

### Notes for certification

Teh Tarik Meter shows the signed-in user's Claude (claude.ai) usage limits. Showing real numbers needs a Claude account, but you don't need one to test the app:

1. Start Teh Tarik Meter. The widget appears at the top right of the screen with a sleeping glass, "Not signed in".
2. Click "Peek at a sample first". The widget shows sample numbers (marked "Sample numbers, not yours" at the bottom): the glass, the countdown, the forecast and the weekly cups.
3. Click the gear icon for Settings. The History tab shows a sample chart. Look and General tabs change the drink, theme, language and text size.
4. Right-click the tray icon for the menu. Ctrl+Alt+T hides and shows the widget.

"Connect Claude Code" is optional and only for people who use the Claude Code command-line tool. It asks before changing anything and edits only Claude Code's own settings file in the user's profile, after saving a backup.

The app makes network requests only to claude.ai (as the signed-in user). The Store version does not update itself.

### Data and privacy answers

- Does the app collect personal information? It accesses the user's claude.ai account to read usage limits. Nothing is sent to the developer or any third party. There is no analytics, advertising or telemetry.
- Where is data stored? Only on the user's PC: settings, an 8-day history of usage percentages, and the claude.ai sign-in cookie (encrypted with the user's Windows account by Electron's cookie encryption).
- Can the user delete it? Yes. Sign out in the tray menu clears the sign-in. Uninstalling the Store app removes its data.

Start with **Private audience** (only the Microsoft accounts you list can find and install it), install it from the Store on your PC, and run the test list below. When everything works, change Visibility to **Public audience**. No new submission is needed for that.

## Partner Center steps

1. In your existing developer account (the one used for Lapis), create a new app and reserve the name **Teh Tarik Meter**.
2. The Product identity values are already in `package.json` (`build.appx`), and the **Store package** workflow builds by itself whenever `package.json` changes on `main` (or run it by hand from Actions). Add the repository variable `STORE_PRODUCT_ID` (9PGTMV7K7MJQ) only if you later want the workflow to upload submissions for you.
3. In GitHub Actions, run **Store package** with Send = none. Download the `.appx` file from the run's artifacts.
4. In Partner Center, start a submission: Pricing and availability (Free, Private audience first), Properties (Productivity, privacy policy URL, support contact), Age ratings (questionnaire), Packages (upload the `.appx`), Store listings (paste the text above, upload the screenshots in order, English and Malay), Submission options (runFullTrust reason and certification notes above).
5. Submit. Certification usually takes 1 to 3 business days.

## Test on your PC before going public

With the Private-audience Store copy installed:

- [ ] The widget starts, and starts again after a Windows restart (startup task).
- [ ] Sign in to Claude works and the numbers match claude.ai › Settings › Usage.
- [ ] Connect Claude Code, send a message in Claude Code, and the glass moves within a second or two. The file `%USERPROFILE%\.teh-tarik-meter\claude-code-feed.json` exists and updates.
- [ ] Your previous status line still shows in Claude Code.
- [ ] Ctrl+Alt+T hides and shows the widget. It hides during a full screen video or PowerPoint slideshow.
- [ ] Settings › About says updates come from the Microsoft Store.
- [ ] Uninstall the GitHub (installer) version first if it is installed, so only one copy runs.
